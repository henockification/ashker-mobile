# App assets

Add the following files for Expo app config (see `app.json`):

- `icon.png` – 1024×1024 app icon
- `splash-icon.png` – splash screen image
- `adaptive-icon.png` – Android adaptive icon foreground (1024×1024)
- `favicon.png` – Web favicon

You can use `npx expo prebuild` and replace the defaults, or add your own assets here.
